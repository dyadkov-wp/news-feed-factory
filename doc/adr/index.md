# Индекс ADR — News Feed Factory

**Обновлено:** 2026-10-02

## Типы ADR

| Тип | Отвечает на вопрос |
| --- | --- |
| `PRODUCT` | Что делаем и зачем |
| `ARCH` | Как устроено внутри |
| `PROC` | Как мы работаем |

## Статусы

| Статус | Значение |
| --- | --- |
| `Proposed` | Предложен, обсуждается, ещё не принят |
| `Accepted` | Принят, действует |
| `Deprecated` | Устарел, но ещё не заменён |
| `Superseded` | Заменён другим ADR |
